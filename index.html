🌐 Optional: automatically load files on GitHub Pages

On a web host, place a file named prompts.json beside this HTML, listing the text files to load. Example:

["ECHO_Method.txt", "Tabernacle_Game.txt", "archives/November_Prompts.md"]

Only files listed in that manifest can be loaded automatically. Local file:// pages usually cannot fetch a manifest due to browser security restrictions. The folder picker works locally instead.
